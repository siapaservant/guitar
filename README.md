# 黑金指板 Ebony Custom

用手機學吉他樂理和指板位置的網頁 App。指板照黑金 Les Paul Custom 的樣子畫：烏木指板、珍珠貝塊狀記號、奶油色包邊和金色配件。

## 功能

- **音階**：12 個調，14 種音階（大調、三種小調、五聲、藍調、7 個調式），可以用級數（1234567）、音名或音程顯示，並且可以隱藏個別級數或切換首調簡譜。
- **CAGED**：大調和小調的 C、A、G、E、D 五個指型，標出和弦按法、對應的音階和五聲音階，也能一次看全部五個指型。
- **和弦**：20 種和弦的公式和組成音，列出開放和弦、6 弦和 5 弦根音的指型，以及各弦組的轉位。
- **順階和弦**：大調、自然小調、和聲小調的三和弦和七和弦，附羅馬數字、功能和五度圈；常見和弦進行（1-6-4-5、卡農、4-5-3-6-2-5-1、2-5-1、12 小節藍調等）可以直接播放。
- **練習**：認位置、找音兩種測驗，統計正確率。
- **樂理**：指板記憶、八度指型、音程、和弦組成、CAGED、順階和弦、調式的筆記。

打開時會先看到整把黑金 Les Paul Custom，點一下會放大進入琴頸。點指板上的任何一個音都會發出聲音，並標出整個指板上所有同名的音。調性、音階、和弦種類、和弦進行和顯示設定都從下方滑出的面板選擇。

## 使用

開啟 GitHub Pages 後，用手機瀏覽器打開網址，再選「加入主畫面」，就能像 App 一樣全螢幕使用。

整個 App 只有一個 `index.html`，沒有需要安裝或建置的東西；也可以直接用瀏覽器打開這個檔案。
